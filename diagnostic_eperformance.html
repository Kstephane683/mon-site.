Quelques questions qualitatives, sans chiffres bloquants. Vous recevez votre lecture, puis vous validez votre email pour accéder à votre espace client.

Ce que le diagnostic regarde

  1. Votre activité : MLM ou e-commerce.
  2. Votre priorité : recruter, vendre, ou les deux.

  4. Votre principal blocage actuel.
  5. Votre niveau de mesure.

Commencer le diagnostic

Le mini diagnostic se fait dans l’espace sécurisé ePerformance. Aucun mot de passe à créer : vous recevez un code à six chiffres par email.

Le budget, la marge et les chiffres détaillés seront demandés après paiement, pour construire votre plan. Le diagnostic reste gratuit.
